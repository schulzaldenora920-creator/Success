# 打单策略 · 即用提示词模板

> 配合 `SKILL.md` 使用。在 Claude Code 里可直接说"用销售打单策略分析XX客户"自动触发；
> 在手机/网页版 AI 里，把下面模板复制过去填空即可。

## 模板 A：新单子开局分析（信息还不全时用）

```
你是资深 ERP 大客户销售战略参谋。请用 MEDDPICC + 决策链地图 + 竞争策略，帮我分析下面这个单子，
产出一份打单作战方案。信息不全的关键项请明确指出并追问，不要凭空假设。

【客户】名称/行业/规模：
【项目】要上的模块/预算/预计签约时间：
【触发事件】客户为什么现在要做：
【已接触的人】姓名-职位-态度：
【经济决策人EB】是谁、见到没：
【内线/教练】有没有：
【现状与痛点】在用什么系统、最大的痛是：
【竞争对手】有谁在跟、客户当前倾向：
【我方进展】已做的动作 + 当前最大卡点：

输出要求：按"健康度判断 / 决策链地图 / 价值主张 / 竞争策略 / 下一步动作"五部分，
下一步动作要具体到"找谁做什么、想达成什么、截止时间"。
```

## 填好的样例（参考怎么填）

```
【客户】华东某制造集团 / 离散制造 / 营收40亿、8家分子公司
【项目】财务+供应链一体化 / 预算约600万 / 计划Q4签约
【触发事件】集团并购后多套系统数据打不通，CFO要统一报表口径
【已接触的人】IT总监(中立,关心实施风险)、财务经理(支持)
【经济决策人EB】分管财务的副总裁——还没见到
【内线/教练】财务经理倾向我们，但影响力一般，没被测试过
【现状与痛点】用着两套老ERP+大量Excel，月结要15天，集团看不清实时数据
【竞争对手】SAP、用友在跟；客户觉得SAP"大牌但贵且实施久"
【我方进展】做过一次产品演示；卡点：见不到副总裁，摸不准决策标准
```

## 测 3 次优化法（来自方法论手册）

1. **第1次**：直接用模板，看输出能不能用
2. **第2次**：补约束（如"价值部分必须给量化数字""动作不超过5条"）
3. **第3次**：质量够用就固化下来，每个新单子都套这个模板

> 评判标准：比你自己从头想省了时间，就算成功。
