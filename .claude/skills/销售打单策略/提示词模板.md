# 打单策略 · 即用提示词模板

> 配合 `SKILL.md` 使用。核心主线：**目标 → 差距 → 根因 → 方案 → 论证最优 → 落地**。
> 在 Claude Code 里直接说"用销售打单策略分析XX项目"自动触发；在手机/网页版 AI 里把模板复制过去填空即可。

## 模板 B：需求去伪存真（信息打架时用）

```

## 模板 C：竞品根因 + 方案论证（客户倾向对手时用）

```
客户当前倾向【对手名】。帮我：
1. 客观对比我方vs竞品（功能/价格/周期/品牌/案例），判断客户倾向背后的深层根因

3. 论证"为什么值得做"+"为什么我方是最优解"，给一段汇报总结陈述。

【背景】（粘贴竞品情况、客户反馈、我方优劣势）：

## 测 3 次优化法（来自方法论手册）

1. **第1次**：直接用模板，看输出能不能用
2. **第2次**：补约束（如"价值必须量化""动作≤3条""红灯项必须给破局动作"）
3. **第3次**：质量够用就固化，每个新项目都套这套模板

> 评判标准：比你自己从头想省了时间，就算成功。
